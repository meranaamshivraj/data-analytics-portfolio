# Sales Data Analysis Using Microsoft Excel

## Project Overview

This project analyzes sales data to identify sales in india, trends, product performance, and regional sales patterns using Microsoft Excel.

## Objectives

* Analyze overall sales performance.
* Identify top-performing products and categories.
* Compare sales across regions.
* Track monthly and yearly revenue trends.
* Present findings through an Excel dashboard.

## Data Cleaning

The analysis will include:

* Checking for duplicate records.
* Identifying missing values.
* Correcting data formats.
* Validating important columns.
* Preparing the cleaned dataset for analysis.

## Analysis Techniques

* Excel formulas and functions.
* PivotTables.
* PivotCharts.
* KPI calculations.
* Dashboard development.

## Key Insights

Insights and recommendations will be added after completing the analysis.
