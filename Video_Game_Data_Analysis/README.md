# 🎮 Video Game Sales Analysis Using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing video game sales data using **Microsoft Excel** to identify sales trends, popular gaming platforms, successful genres, and regional market performance.

The dataset contains video game-related information, such as game titles, platforms, genres, publishers, release years, and sales across different regions, depending on the available columns.

The objective of this project is to transform raw video game sales data into meaningful business insights through data cleaning, KPI development, Pivot Tables, charts, and dashboard creation.

Using Microsoft Excel, I cleaned and organized the dataset, performed sales analysis, created interactive visualizations, and developed a dashboard to present key findings clearly.

## 🎯 Project Objectives

* Clean and prepare raw video game sales data using Microsoft Excel.
* Identify and remove duplicate records where appropriate.
* Handle missing and inconsistent values.
* Analyze sales performance across gaming platforms and genres.
* Identify top-performing games and publishers.
* Compare sales across different geographical regions.
* Create Pivot Tables and charts for meaningful analysis.
* Develop a professional dashboard to summarize key performance indicators.
* Generate insights to support data-driven business decisions.

## 📊 Key Performance Indicators (KPIs)

The project focuses on video game sales performance through KPIs such as:

* **Total Global Sales:** Total video game sales across all available regions.
* **Total Games:** Number of distinct game titles in the dataset.
* **Total Platforms:** Number of distinct gaming platforms represented.
* **Total Publishers:** Number of distinct publishers represented.
* **Top-Selling Game:** Game with the highest global sales.
* **Top Gaming Platform:** Platform with the highest combined sales.
* **Top Genre:** Genre generating the highest total sales.
* **Regional Sales:** Sales performance across North America, Europe, Japan, and other regions, where available.

*Note: KPIs depend on the columns available in the dataset. Sales figures should be calculated using the dataset's actual values and units.*
