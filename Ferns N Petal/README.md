# FNP Sales Analysis Dashboard | Excel Project

## 📌 Project Overview

This project focuses on analyzing sales data from Ferns N Petals (FNP) using Microsoft Excel. The objective is to transform raw data into meaningful business insights through data cleaning, KPI analysis, Pivot Tables, and an interactive sales dashboard.

## 🎯 Project Objectives

* Analyze overall sales performance.
* Understand customer purchasing behavior.
* Evaluate product and category performance.
* Identify sales trends and business opportunities.
* Present key findings through an Excel dashboard.

## 🗂️ Dataset Description

The Excel workbook contains three main data sheets:

* **Orders:** Contains order-related information used for sales analysis.
* **Products:** Contains product information used to analyze product performance.
* **Customers:** Contains customer information used to understand customer behavior.
