# 🛍️ Retail Store Sales Analysis Using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing retail store sales data using **Microsoft Excel** to generate meaningful business insights. The dataset contains customer, product, gender, sales channel, and transaction-related information from both online platforms and physical store transactions.

The analysis covers online marketplaces such as **AJIO, Flipkart, and Myntra**, along with in-store purchases. The project aims to understand customer purchasing behavior, sales performance, product demand, and differences between male and female customers.

I used Excel to clean and prepare the raw dataset, create Key Performance Indicators (KPIs), build Pivot Tables, develop charts, and design an interactive sales dashboard for business reporting.

## 🎯 Project Objectives

* Clean and prepare raw retail sales data using Microsoft Excel.
* Remove duplicate records and check data consistency.
* Analyze sales performance across online platforms and physical stores.
* Compare purchasing patterns between male and female customers.
* Create Pivot Tables to summarize sales data across different categories.
* Develop KPIs and charts to track business performance.
* Build a professional dashboard to support data-driven decision-making.

## 📊 Key Performance Indicators (KPIs)

The project focuses on retail sales performance through KPIs such as:

* **Total Revenue:** Overall sales generated from transactions.
* **Total Orders:** Number of unique orders or transactions.
* **Total Customers:** Number of unique customers, if customer identifiers are available.
* **Average Order Value (AOV):** Average revenue generated per order.
* **Online Sales:** Sales generated through online marketplaces.
* **In-Store Sales:** Sales generated through physical store transactions.
* **Gender-Based Sales:** Sales contribution from male and female customers.
* **Platform-Wise Sales:** Revenue comparison across AJIO, Flipkart, and Myntra.

*Note: KPIs are calculated based on the available dataset columns and the definitions used in the workbook.*

## 📈 Pivot Tables & Data Visualization

Created Pivot Tables and charts in Excel to explore different aspects of retail performance.

The analysis includes:

* Sales comparison across online platforms and physical stores.
* Revenue contribution by sales channel.
* Male vs. female customer sales comparison.
* Product and category-wise sales analysis, where applicable.

Charts help present the findings clearly and make sales patterns easier to understand.
