# 🏏 IPL Data Analysis Dashboard | Excel Project

## 📌 Project Overview

This project focuses on analyzing Indian Premier League (IPL) data using Microsoft Excel. The objective is to clean raw data, calculate key performance indicators (KPIs), create Pivot Tables, and develop an interactive dashboard to explore cricket match statistics and team performance.

## 🎯 Project Objectives

* Clean and prepare raw IPL data for analysis.
* Calculate key performance indicators (KPIs).
* Analyze team and match performance.
* Explore player statistics and match outcomes.
* Create Pivot Tables and Pivot Charts.
* Build a dashboard to present meaningful insights.
